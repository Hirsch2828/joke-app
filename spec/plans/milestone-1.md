# תוכנית Milestone 1: Walking Skeleton

## המטרה
הדף והפונקציה באוויר ב-Vercel, באותה כתובת, ומדברים זה עם זה. המפתח שמור ב-Vercel, אבל עוד בלי AI: הפונקציה רק מחזירה בדיחה זמנית ואומרת אם המפתח קיים.

## מצב התחלתי (נבדק)
- קיימים: `.gitignore` (כולל `.env`, `.env.*`, `!.env.example`, `.vercel`, `node_modules`), `.env.example`, `.claude/settings.json` (חוסם קריאת `.env` ו-`.env.*`), `CLAUDE.md`, תיקיית `assets/` עם כל ה-SVG וה-PNG.
- חסרים: `index.html`, `api/joke.js`, `package.json`.
- אין לגעת ב-`.env.example` (אסור לקרוא `.env.*`). רק לוודא שהוא קיים בקומיט. אם חסר, ליצור עם השורה `OPENAI_API_KEY=` בלבד.

## 1. api/joke.js
- `export default { async fetch(request) { ... } }`.
- לא POST: מחזיר 405 עם `{ "error": "..." }` בעברית, JSON.
- POST: קורא את הגוף ב-`try/catch`. גוף שבור נחשב "אין נושא". חותך את `topic` ל-100 תווים (מחרוזת בלבד, אחרת ריק).
- בודק `process.env.OPENAI_API_KEY`: ריק או חסר = "חסר", אחרת "נמצא". רק כן/לא, לעולם לא הערך עצמו.
- `console.log` קצר בכל קריאה (הנושא והאם המפתח נמצא), כדי שיופיע ב-Logs של Vercel (תנאי 4).
- מחזיר JSON עם הכותרת `content-type: application/json`:
  `{ "joke": "בדיחה זמנית מהשרת: [הנושא]. המפתח: נמצא" }` (או "חסר").
  נושא ריק: נוסח סביר ("בדיחה זמנית מהשרת: [בלי נושא]...").
- בלי כותרות CORS ובלי טיפול ב-OPTIONS (תנאי 5).

## 2. index.html
- `<html lang="he" dir="rtl">`, `viewport`, כותרת "בדיחה בלחיצה".
- גופנים מ-Google Fonts: Fredoka (500, 600, 700) ו-Playpen Sans Hebrew (500), עם גיבוי `system-ui`.
- פריסה לפי DESIGN.md ו-mockups.png, מלמעלה למטה, ברוחב מקסימלי 440, ריפוד צדדים 18, מרווח 14:
  1. `assets/logo.svg` במרכז, רוחב 300.
  2. שורת הסבר: "כותבים נושא, לוחצים, וצוחקים. בלי נושא, מקבלים בדיחה כללית." (דיו רך, 17/500).
  3. תווית "על מה הבדיחה?" (18/600), מקושרת לתיבה עם `for`. תיבה: `maxlength="100"`, placeholder "למשל: חתולים", גודל 19/500, פינות 18, מסגרת 3, צל קשה 4x4, סיבוב 0.6°, בפוקוס טבעת כחולה 4.
  4. כפתור "תנו לי בדיחה!": גלולה, גובה 64 לפחות, רוחב מלא, אדום `#F23D2F`, טקסט לבן 24/700, מסגרת 3, צל קשה 8, סיבוב 1°. ב-`:active` יורד 6 והצל 2.
  5. בועה: `aria-live="polite"`, `data-state="idle"`, פינות 28, מסגרת 3, צל 6x6, סיבוב 1.2- מעלות, גובה מינימלי 190. בתוכה תמונת הדמות (118) וטקסט: "לוחצים על הכפתור, והבדיחה מופיעה כאן".
  6. תחתית: "מיישם AI ואוטומציה · 53500", 13, דיו רך.
- רקע: `#FFE15A`, `assets/bg-dots.svg` חוזר, ו-`assets/bg-doodles.svg` פעם אחת למעלה במרכז (שכבה נפרדת, לא מעל הטקסט).
- צבעים כפי שב-DESIGN.md (דיו `#2B1E4A`, נייר `#FFFFFF`, שגיאה `#C0261B`, ורוד שגיאה `#FFE8EC`, רמז `#756B92`). הקבצים של assets משמשים כמו שהם, בלי לצייר מחדש.
- בניית הדף כבר ל-4 המצבים באופן מינימלי, כי זה הוא ה"שלד" ש-Milestone 2 משלים: `data-state` מחליף את תמונת הדמות (idle/think/joke/error) ואת עיצוב הבועה. ב-Milestone 1 בפועל נעשה שימוש ב-idle, think (בזמן ההמתנה), joke (אחרי תשובה) ו-error (אם הבקשה נכשלה, עם הודעה בעברית). אנימציות התנועה המלאות והגימורים נשארים ל-Milestone 2.
- JavaScript:
  - שליחת הטופס (כפתור או Enter) -> `fetch('/api/joke', { method: 'POST', headers: {'content-type':'application/json'}, body: JSON.stringify({ topic }) })`. כתובת יחסית, אותה כתובת של האתר.
  - בזמן המתנה: כפתור נעול וכותב "חושב...", מצב think, טקסט "מחפש בדיחה על [הנושא]..." (או "מחפש בדיחה...").
  - הצלחה: מציג `joke` ב-`textContent` בלבד (לא innerHTML), מצב joke, כפתור "עוד בדיחה!".
  - כישלון (רשת או סטטוס לא תקין): מצב error, הודעה קצרה בעברית, כפתור "לנסות שוב".
- `prefers-reduced-motion`: בלי תנועה.
- נגישות: ניגודיות לפי המסמך, `aria-live` על הבועה, תווית גלויה לתיבה.

## 3. בדיקות עצמיות לפני שעוצרים
- אין `vercel` מותקן בהכרח אצל המשתמש. לבדוק בעצמי: הרצת הפונקציה ישירות בנוד (ייבוא `api/joke.js` וקריאה ל-`fetch(new Request(...))`) עם ובלי `OPENAI_API_KEY` בסביבה של התהליך, ללא קובץ מפתח, ועם GET (צפוי 405).
- בדיקת הדף בדפדפן המובנה בעזרת שרת סטטי זמני עם stub ל-/api/joke שנכתב לתיקיית ה-scratchpad (לא לפרויקט), בגודל 375 ו-390 פיקסל. מוודא RTL, ארבעת המצבים, שהכפתור נעול בזמן המתנה, ובלשונית Network בקשה אחת ל-/api/joke.
- חיפוש בקוד: אין `Access-Control` ואין `OPTIONS`; אין `sk-`; אין `innerHTML`.
- סוגרים כל שרת שהרצתי.

## 4. מה המשתמש עושה בידיים (הדרכה צעד אחר צעד, אחרי הבנייה)
Claude לא מבקש מפתח ולא נוגע בו.
1. אחרי "דחוף שינויים לגיטהאב": ב-Vercel -> New Project -> Import לריפו `Hirsch2828/joke-app` -> Framework Preset: **Other** -> Deploy.
2. ב-OpenAI, API keys: ליצור מפתח בשם `joke-in-a-click`.
3. ב-Vercel, Settings -> Environment Variables: שם `OPENAI_API_KEY`, הערך המפתח, סוג Secret, סביבות Production ו-Preview. אחר כך Redeploy.
4. רשות, הרצה מקומית: מפתח dev בשם `joke-in-a-click-dev`, `cp .env.example .env.local`, להדביק את המפתח אחרי `=` בעצמו, `npm i -g vercel`, `vercel login`, `vercel link`, `vercel dev` ופתיחת http://localhost:3000.

הערה: לפני שמגדירים את המפתח, התשובה תהיה "המפתח: חסר". זה צפוי ונכון, ואחרי ה-Redeploy היא תהפוך ל"נמצא".
